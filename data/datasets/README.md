# Traffic datasets

No raw or processed traffic datasets have been uploaded to this directory. It is reserved for any data subsets that may be shared separately in accordance with the original providers' terms.

The datasets used in the manuscript are available through their original projects:

- Mon(IoT)r: <https://moniotrlab.khoury.northeastern.edu/publications/imc19/>
- UNSW IoT traces: <https://iotanalytics.unsw.edu.au/iottraces.html>

These links identify the original datasets. The exact subset used for an experiment requires its device/date/record selection manifest; those manifests are not currently included here.
